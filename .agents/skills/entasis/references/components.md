# Components and entrypoints

Generated by `npm run generate:component-contract` from `tooling/component-contract/manifest.ts`. Do not edit.

Every public component, utility and entrypoint, by category. Pick from here before writing markup of your own.

Each link is that entry's full documentation as Markdown (props, data model, theme parts, accessibility). Read the copy that matches the installed version first:

- `node_modules/entasis/docs/components/<name>.md`, where `<name>` is the link's file name (`card.md`), and `node_modules/entasis/docs/llms.txt` for this index with one line per page;
- the link itself, the docs site's copy of the latest release;
- the `components` tool of the entasis MCP server (https://entasis.beynar.workers.dev/mcp), which returns the same text.
