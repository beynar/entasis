Generated by `npm run generate:component-contract` from `SegmentedControl`'s theme file. Do not edit.

- Registry key: `segmented-control`, the key under `<Theme components>`
- Setter: `setSegmentedControlTheme` from `entasis/segmented-control`

- Override order: your classes land after the part's base, variant and compound classes, so a plain Tailwind class in an override's `base` beats any of them; the instance `class` prop lands last.
