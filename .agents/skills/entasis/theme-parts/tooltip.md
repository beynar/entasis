# tooltip theme parts

Generated by `npm run generate:component-contract` from `Tooltip`'s theme file. Do not edit.

- Registry key: `tooltip`, the key under `<Theme components>`
- Setter: `setTooltipTheme` from `entasis/tooltip`
- Parts: 2. Each part takes `base` plus one map per variant in the `theme` prop, the setter and the registry alike.
- Override order: your classes land after the part's base, variant and compound classes, so a plain Tailwind class in an override's `base` beats any of them; the instance `class` prop lands last.

## `motion`

- Reserved `motion` slot, a transition spec rather than classes. Base: `{ in: { x: 0, y: 2, scale: 0.98, opacity: 0 }, out: { x: 0, y: 2, scale: 0.98, opacity: 0 }, duration: 'fast' }`
