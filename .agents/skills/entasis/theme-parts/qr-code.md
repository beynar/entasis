# qr-code theme parts

Generated by `npm run generate:component-contract` from `QRCode`'s theme file. Do not edit.

- Registry key: `qr-code`, the key under `<Theme components>`
- Setter: `setQRCodeTheme` from `entasis/qr-code`
- Parts: 1. Each part takes `base` plus one map per variant in the `theme` prop, the setter and the registry alike.
- Override order: your classes land after the part's base, variant and compound classes, so a plain Tailwind class in an override's `base` beats any of them; the instance `class` prop lands last.

## `root`

- Element: `<svg>`
- Variants: `size` (small | **normal** | large) · `color` (primary | secondary | danger | success | warning | info | **neutral**) — bold is the default
- Base: `block aspect-square`
- `size`: small → `size-24` · normal → `size-32` · large → `size-48`
- `color`: primary → `text-primary` · secondary → `text-secondary` · danger → `text-danger` · success → `text-success` · warning → `text-warning` · info → `text-info` · neutral → `text-neutral`
