# grid theme parts

Generated by `npm run generate:component-contract` from `Grid`'s theme file. Do not edit.

- Registry key: `grid`, the key under `<Theme components>`
- Setter: `setGridTheme` from `entasis/grid`
- Parts: 2. Each part takes `base` plus one map per variant in the `theme` prop, the setter and the registry alike.
- Override order: your classes land after the part's base, variant and compound classes, so a plain Tailwind class in an override's `base` beats any of them; the instance `class` prop lands last.
