# collapsible theme parts

Generated by `npm run generate:component-contract` from `Collapsible`'s theme file. Do not edit.

- Registry key: `collapsible`, the key under `<Theme components>`
- Setter: `setCollapsibleTheme` from `entasis/collapsible`
- Parts: 5. Each part takes `base` plus one map per variant in the `theme` prop, the setter and the registry alike.
- Override order: your classes land after the part's base, variant and compound classes, so a plain Tailwind class in an override's `base` beats any of them; the instance `class` prop lands last.
