# markdown theme parts

Generated by `npm run generate:component-contract` from `Markdown`'s theme file. Do not edit.

- Registry key: `markdown`, the key under `<Theme components>`
- Setter: `setMarkdownTheme` from `entasis/markdown`
- Parts: 1. Each part takes `base` plus one map per variant in the `theme` prop, the setter and the registry alike.
- Override order: your classes land after the part's base, variant and compound classes, so a plain Tailwind class in an override's `base` beats any of them; the instance `class` prop lands last.

## `root`

- Element: `<svelte:element>`
- Variants: `size` (small | **normal** | large) · `inline` (true | **false**) — bold is the default
- Base: _none_
- `size`: small → _none_ · normal → _none_ · large → _none_
- `inline`: true → _none_ · false → `w-full min-w-0`
- Compound: inline=false & size=small → `text-xs leading-normal` · inline=false & size=normal → `text-sm leading-relaxed` · inline=false & size=large → `text-base leading-relaxed`
